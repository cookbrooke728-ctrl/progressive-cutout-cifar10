# Progressive Cutout on CIFAR-10

Course reproduction by Lingxiao Liu, North China Electric Power University.

This repository compares a CIFAR ResNet-20 baseline, Cutout, fixed-probability Cutout, and a linear probability schedule. The experiment protocol uses three seeds and 100 epochs per run. Formal training is currently in progress. Results and weights will be added after all runs and the independent test evaluation finish.

No unmeasured performance numbers are reported.
